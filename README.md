## 什么是 Galgame

**Galgame**（日语：ギャルゲーム，英文常写作 *bishōjo game* 或 *dating sim*）是一种以美少女角色为核心、以文字叙事为主要表现形式的电子游戏类型。玩家通常扮演男性主角，通过与多位女性角色互动、选择对话分支，推进剧情并最终达成不同结局。

Galgame 的核心是 **“叙事交互”**——玩家的选择不仅影响故事走向，更深度介入角色的情感发展。它介于传统小说与电子游戏之间，被称为“视觉小说”（Visual Novel）或“文字冒险游戏”（Adventure Game）的亚种。

> **一句话定义**：Galgame 是用“选择”书写的互动式青春故事。

## 发展简史

| 时期 | 关键事件 |
|------|----------|
| **1980年代** | 日本PC-88/98平台出现早期恋爱模拟游戏，如《天使们的午后》（1985），奠定“文字+选择”基础。 |
| **1990年代** | 家用机（PC Engine、SFC）引入，Leaf 和 Key 社崛起。《心跳回忆》（1994）成为现象级作品，将“数值养成”与恋爱结合。 |
| **2000年代** | 全年龄与成人向分流，视觉小说引擎（如NScripter、吉里吉里）普及，同人创作爆发。《秋之回忆》《CLANNAD》等名作诞生。 |
| **2010年代** | 多平台（PSP、PSV、Steam）全球化，中文化浪潮兴起。欧美独立视觉小说（如《DDLC》）反向影响日本业界。 |
| **2020年代** | VR/AR尝试，AI辅助剧本创作，Galgame 与手游、动漫联动成为常态，受众进一步扩大。 |

## 主要类型与题材

Galgame 按风格和主题可大致分为以下几类：

### 🌸 学园纯爱
- 背景多为高中，讲述校园日常与青春悸动。
- 代表作：《CLANNAD》《樱花庄的宠物女孩》《白色相簿2》（序章）

### 🌌 奇幻冒险
- 融入异世界、魔法、战斗等幻想元素。
- 代表作：《Fate/stay night》《Muv-Luv Alternative》《秽翼的尤斯蒂娅》

### 😂 轻松喜剧
- 以搞笑和温暖日常为主，角色互动充满吐槽和颜艺。
- 代表作：《恋爱0公里》《碧蓝航线 Crosswave》（外传）

### 😭 催泪治愈（泣きゲー）
- 情感冲击强烈，常涉及生死、家庭、记忆等深刻话题。
- 代表作：《AIR》《Kanon》《星之梦》

### 🕵️ 悬疑/心理
- 结合推理、心理战或 meta 元素，挑战玩家认知。
- 代表作：《Ever17》《命运石之门》《DDLC》

### 🔞 成人向（18禁）
- 包含性描写内容，通常仅限日本地区发售，但全球爱好者通过海外渠道获取。

## 核心玩法与机制

Galgame 的操作看似简单，却暗藏设计巧思：

- **选项分支**：在关键节点出现 2~4 个选项，直接影响好感度、剧情线甚至结局（Bad End / Normal End / True End）。
- **好感度系统**：通过对话选择、礼物赠送等累积特定女主角的隐藏数值，解锁专属路线。
- **多周目设计**：单次通关仅能窥见故事一角，鼓励玩家反复游玩收集全结局。
- **地图/行动点（部分作品）**：在特定时段选择前往地点或学习技能，如《心跳回忆》的日程管理。
- **攻略辅助**：现代游戏内置路线图或提示功能，降低挫折感。

> 优秀的 Galgame 会让玩家感到“我的选择真实地改变了角色的命运”。

## 视觉与音乐的魅力

### 视觉
- **立绘**：角色在对话时呈现的全身或半身插图，表情随情绪切换。
- **CG（计算机图形）**：关键剧情时播出的精美静态画，通常是全屏插画，成为玩家收藏目标。
- **背景与演出**：场景图、雨天/黄昏等氛围变化，配合文字渐变、震动等效果增强沉浸感。

### 音乐
- **BGM（背景音乐）**：每场景专属配乐，烘托情绪（如《鳥の詩》之于《AIR》）。
- **主题曲**：OP/ED 由专业歌手演唱，常成为 ACG 名曲。
- **音效**：脚步声、风声、开关门声等细节增强真实感。

许多 Galgame 的原声带单独发售，并举办线下音乐会。

## 社群与文化影响

- **同人创作**：大量同人社团制作免费或低价 Galgame，成为日本 Comiket 的重要组成部分。
- **跨媒体企划**：热门作多被改编为TV动画、剧场版、轻小说或舞台剧（如《Key社三部曲》《Fate/UBW》）。
- **角色经济**：女主角成为虚拟偶像，衍生手办、抱枕、主题咖啡厅等周边产业。
- **情感教育**：部分作品深刻探讨恋爱观、家庭观，对玩家心理健康产生积极或引发反思的影响。
- **全球社区**：英文/中文粉丝翻译组活跃，Steam 上架官方中文版，让非日语玩家也能接触。

## 争议与批评

1. **性别刻板印象**：多数 Galgame 以男性视角展开，女性角色常被物化为“攻略目标”，引发女权主义批评。
2. **成人内容合法性问题**：日本法律允许成人向游戏，但海外发行常被审查或封禁，引发自由与道德争论。
3. **沉溺风险**：部分玩家过度投入虚拟恋情，影响现实社交，被媒体称为“二次元禁断症候群”。
4. **艺术性争议**：批评者认为多数作品套路化，缺乏文学深度；支持者则强调互动叙事独特价值。

业界正逐步增加女性向（乙女游戏）、LGBTQ+题材作品，尝试打破传统框架。

## 结语

Galgame 是日本 ACG 文化中的一颗独特明珠，它以文字、图像、音乐和交互编织出“可以走入的梦境”。无论你是寻求催泪治愈、悬疑烧脑，还是单纯想体验一段别样人生，总有一部作品能击中你的心。
